Resumen

AquariumAI no recopila datos de telemetría, no requiere cuenta de usuario ni registro. Todos tus datos (acuarios, tareas, población, fotos, valores del agua, historial de dosificación) permanecen exclusivamente en tu dispositivo. No existe un servidor propio de por medio.

Qué datos van a dónde

Hay exactamente dos situaciones en las que la app se comunica con un servicio externo — ambas directamente desde tu dispositivo, sin ningún servidor nuestro de por medio:

1. Fichas de cuidado con IA (función opcional, desactivada por defecto)

Si activas esta función y obtienes una ficha para una especie, se envía únicamente el nombre de la especie a la API de Claude de Anthropic (api.anthropic.com). No se transmiten datos de acuarios, fotos, ubicación ni otros datos de usuario. La solicitud usa tu propia clave API de Anthropic, proporcionada por ti mismo (bring-your-own-key) — la app no incluye ninguna clave propia ni obtiene beneficio del uso. Tu clave API se guarda cifrada en el Android Keystore y solo sale del dispositivo para autenticarse ante la API de Claude. El tratamiento de estas solicitudes por parte de Anthropic se rige por su propia política de privacidad (anthropic.com/legal/privacy).

2. Sugerencias de fotos para entradas de población (parte de la misma función opcional de IA)

Al buscar fotos para una ficha, se envía el nombre de la especie (normalmente el científico) a la API abierta de Wikimedia Commons (commons.wikimedia.org, meta.wikimedia.org) para sugerir fotos libres de licencia. No se transmiten datos personales ni de uso — solo el término de búsqueda, como en cualquier búsqueda web normal.

Qué más permanece local

  • Datos de acuarios, tareas, población y valores del agua en una base de datos local en tu dispositivo.
  • Fotos que tomes o selecciones, guardadas en el almacenamiento interno de la app.
  • Una copia de seguridad JSON opcional se guarda donde tú decidas — compartirla (p. ej. por correo electrónico) es tu propia responsabilidad.

Permisos y para qué se usan

  • Internet — solo para los dos casos opcionales anteriores (ficha con IA, búsqueda de fotos).
  • Cámara — para fotos que tomes de tu población; las fotos se guardan solo localmente.
  • Notificaciones, alarmas exactas, receptor de arranque, vibración, wake lock — exclusivamente para recordatorios locales de tareas de cuidado pendientes; no se transmiten datos para esto.

Compartición con terceros

Aparte de los dos casos descritos arriba, que activas tú mismo (Anthropic, Wikimedia), no hay compartición de datos con terceros. Sin venta de datos, sin seguimiento, sin publicidad, sin servicios de análisis o reporte de fallos.

Tus derechos

Como todos los datos de la app viven exclusivamente en tu dispositivo, siempre tienes el control total: consulta, modificación y eliminación directamente en la app o desinstalándola. Para preguntas sobre los dos servicios externos, contacta con el proveedor correspondiente (Anthropic, Wikimedia) o con nosotros en la dirección de contacto indicada arriba.
